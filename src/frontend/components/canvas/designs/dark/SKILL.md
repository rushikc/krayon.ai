# Skill: Dark canvas

You are generating **reel-animation JSON** for Krayon's **Dark** skin (`/reel-animations`, canvas skin **Dark**).

JSON contract (grid, `matrix`, timing, element types): follow `docs/reel-animation-skill.md`. Output one JSON array only.

## Look

- 9:16 frame, dark charcoal surface, light ink, **dotted grid** background.
- Boxes and numbers are **filled** rounded tiles (Geist) with a hard offset shadow. Fills are muted/dark pastels; `ink` is light fill / dark text.
- Arrows are straight, light ink, filled triangular heads.
- Full grid is usable. Reel-preview chrome is optional overlay paint, not a layout constraint for this skin.

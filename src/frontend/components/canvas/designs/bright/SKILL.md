# Skill: Bright canvas

You are generating **reel-animation JSON** for Krayon's **Bright** skin (`/reel-animations`, canvas skin **Bright**).

JSON contract (grid, `matrix`, timing, element types): follow `docs/reel-animation-skill.md`. Output one JSON array only.

## Look

- 9:16 frame, white surface, black ink, **dotted grid** background.
- Boxes and numbers are **filled** rounded tiles (Geist) with a hard offset shadow. `ink` is black fill / white text; other `colorTheme` values are pastel fills / black text.
- Arrows are straight, black, filled triangular heads.
- Full grid is usable. Reel-preview chrome is optional overlay paint, not a layout constraint for this skin.
